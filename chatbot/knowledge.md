## Work Projects

### XFiles AI Assistant (Microsoft)
- **What it is:** An AI-powered incident resolution assistant for the Azure Files team.
- **How it works:** Ingests Troubleshooting Guides (TSGs) and two years of historical incident data into a vector store. When a new incident fires, the assistant retrieves relevant past incidents and runbook steps to help engineers resolve issues faster.
- **Impact:** Reduces mean time to resolution (MTTR) for livesite incidents; surfaces institutional knowledge that would otherwise require an experienced engineer to recall.
- **Tech:** Vector embeddings, retrieval-augmented generation (RAG), Azure AI services.

### E*Trade Calc Engine (Morgan Stanley)
- **What it is:** Account calculation engine rebuilt post-merger when Morgan Stanley acquired E*Trade.
- **Impact:** Achieved an **8× speedup** in account calculation performance after the migration and optimization effort.
- **Context:** The merger required reconciling two large financial platforms; the calc engine sits in a critical path for account data.

### Regression Framework (Morgan Stanley)
- **What it is:** A microservice for analyzing exchange margin across three financial centers — New York, London, and Hong Kong.
- **Purpose:** Detects regressions in margin calculations across exchanges, ensuring correctness and consistency after code changes.
- **Scope:** Covers multiple global exchanges and time zones; runs as part of CI/CD pipelines.

## Hobby Projects

### VM Manager
- **What it is:** A personal dashboard for managing Azure spot VMs across all 35 Azure regions.
- **Why:** Spot VMs are up to 90% cheaper than on-demand — but they can be evicted. This tool makes it easy to find the cheapest available region and spin up / tear down VMs.
- **Tech:** Node.js, Azure SDK, web dashboard UI.
- **Impact:** ~90% cost savings on personal cloud compute.

### AI Video Analyzer
- **What it is:** A tool for running AI analysis on long videos.
- **Features:** Session management so analysis can be paused and resumed; intelligent chunking to handle videos that exceed model context limits.
- **Use case:** Summarization, Q&A, and content extraction from long-form video content.

### AI-Powered Livesite Triage
- **What it is:** Automated root cause analysis tool for production incidents.
- **Features:** Incident pattern matching against historical data; automated hypothesis generation for root cause.
- **Impact:** Cuts time spent in initial triage by surfacing the most likely cause before an engineer digs in.

### AI-Driven Engineering Workflows
- **What it is:** A suite of tools that apply AI to software engineering processes.
- **Features:** A/B test automation (design, run, analyze); performance regression detection (flags statistically significant slowdowns in CI).
- **Goal:** Make engineering decisions more data-driven and reduce manual analysis work.
